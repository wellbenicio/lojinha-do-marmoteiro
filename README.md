# Lojinha do Marmoteiro — Artigos Religiosos

Gestor de solicitações de orçamento, pedidos, pagamentos e lotes de compras.

O produto será desenvolvido em Next.js com App Router, JavaScript, Tailwind CSS,
Firebase Authentication, Cloud Firestore e Vercel Blob, conforme a especificação
técnica do projeto.

## Desenvolvimento

O repositório usa `main` para produção, `dev` para integração e `feature/*` para
novas implementações. Consulte [docs/GIT_FLOW.md](docs/GIT_FLOW.md) antes de
publicar alterações.

## Estado atual

Repositório inicializado. O bootstrap da aplicação será realizado na próxima
etapa, depois da definição da identidade visual.
